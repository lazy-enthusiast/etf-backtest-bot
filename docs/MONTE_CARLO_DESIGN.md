# 區塊重排（已按 Sandy 的決定實作）

歷史滾動成功率仍是主指標。重排只能放在新欄位 `monteCarlo`，出現在概況裡獨立的「進階：區塊重排」。不寫進 `successRate`，不塗圓環，不與歷史百分比平均。

這不是幾何布朗運動，也沒有自填預期報酬。

## 已定口徑

1. **計價。** 結果用港元計算。美元開支全程按 1 美元 = 7.8 港元換，沒有算換匯費用，也不代表外國當地物價。其他幣別直接拒絕。這句只出現在概況。
2. **抽什麼。** 抽的是已經換成港元、扣過費用與通膨的那條實質月報酬。下滑打開時，兩袖和該月通膨共用同一個月份索引。不把每一檔分開抽，也不把通膨另抽一次。
3. **塊。** 預設 **12** 個月。進階區可改 **6–60**，但不會長過這段歷史。畫面寫出不重疊的塊數；不到 4 塊會註明起伏很大。一塊是歷史上連續的月份，塊內不環繞。旋鈕是 `reshuffleBlock`／`reshuffleSeed`，與舊的 `bootstrapBlock`／`pathMode: 'bootstrap'` 無關。舊拔靴走同一條港元實質月報酬，但塊可以繞過序列頭尾，而且會改寫圓環。
4. **條數與種子。** **1,000** 條。種子預設 1，畫面上看得到。換種子會有抽樣起伏。以後可以再加條數；v1 不把條數做成預期報酬。
5. **太短就不報。** 實質月報酬少於 **120** 個月（10 年）時，不報「重排後達成比例」。歷史模擬自己的循環警告保持原樣。
6. **旁邊的支出。** P10／P50 是固定實質、今日購買力、各年實質金額相同、期末花完的偏低門檻與中位。放在 `monteCarlo.sustainableSpending`，字體較淡，不覆蓋歷史可花金額。
7. **畫面。** 圓環仍是歷史起始月占比。進階區寫明這不是預測。結果標成「重排後達成比例」，不用「機率」或「勝率」。概況另列匯率說明、美國物價、以及「較早資料不含派息時港股會偏低」。

## 舊拔靴開關

`pathMode: 'bootstrap'` 仍然會把那一次 walk 的 `successRate` 改成拔靴占比。新功能不走這條。兩個塊長不要混用。
