# 退休航道

瀏覽器裡的 ETF 退休規劃。用歷史價格做滾動壓力測試：每個歷史起始月各走一次累積與提領，看計劃撐到終點的比例，以及大約能花多少。計算在瀏覽器完成。這不是報酬預測；成功率是歷史起始月的占比，不是未來機率。

口徑與限制見 [docs/METHODOLOGY.md](docs/METHODOLOGY.md)。

## 這個工具做什麼

- 組合用月報酬回測。部分價格序列不含股息。Sharpe 用 rf＝0。起始月彼此重疊；歷史短於計劃時，序列可以循環。
- 持倉要寫 `TICKER.EX`（`VTI.US`、`IGLN.L`、`VWRD.L`、`2800.HK`）。不會把裸代號默默改成 `.L`。
- 幣別是標籤，模擬裡不換匯。若有可花金額，畫面上另附港幣壓力行（美元下跌 10% 與 20%），只改顯示。
- 概況只顯示重點。點一個起始月可看該路徑的年表，也可匯出全部路徑 CSV。Sharpe／Sortino／Calmar 收在組合績效的進階裡；逐年報酬表預設收合。
- 「ETF 組合權重」與「退休計劃假設」預設收合。標題粗體，摘要是一般字重：組合是代號與權重，計劃是年齡、本金、每月投入與年支出。

可選模組預設關閉。關閉時，舊的計劃與組合會得到和以前相同的成功率與可持續支出。包括持倉上的股息稅負拖累（估計）、下滑路徑對照、現金桶、支出曲線、一次性支出、分段其他收入，以及歷史與區塊拔靴並列。對照標成概念建議或估計，不用新數字取代關閉時的結果。

## 本機

需要 Node.js 18 或以上。

```
npm install
npm run dev
```

瀏覽器開 http://127.0.0.1:5173 。`npm run fetch` 只更新合成序列與 CPI；一般 ETF 價格經 Worker 向 Yahoo 取得。
